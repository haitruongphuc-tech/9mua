# Font cho máy chủ vẽ chữ lên video

`BeVietnamPro-ExtraBold.ttf`: Be Vietnam Pro ExtraBold (giấy phép SIL Open Font License 1.1, xem `OFL.txt`), ghép từ ba
phần Latin, Latin mở rộng và tiếng Việt của gói `@fontsource/be-vietnam-pro` thành một file đủ dấu. ffmpeg (drawtext) dùng
file này để vẽ chữ và nhãn dán khi xử lý video (SPEC-creator.md V5.6 mục 1).
